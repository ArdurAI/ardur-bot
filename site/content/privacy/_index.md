This page covers **this website**, `bot.ardur.ai`. It does not cover a self-hosted deployment of
{{< product >}} itself, which is operated by whoever runs it.

## This site collects nothing

This site is static HTML generated by Hugo and published to GitHub Pages. It:

- Sets no cookies and runs no client-side tracking script.
- Uses no analytics service, and no third-party embeds, fonts, or CDNs.
- Has no sign-in, no accounts, and no server-side code of its own — there is nothing here that
  could store what you typed or clicked.

The only information this site sends anywhere is the ordinary HTTP request your browser makes to
load a page. That request passes through GitHub Pages, the hosting provider, which may keep
standard web-server access logs (request time, path, and IP address) under
[GitHub's own privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
The {{< product >}} project does not add anything to that logging and cannot see it.

## Links to GitHub

This site links to the [{{< product >}} repository]({{ .Site.Params.repoURL }}) for documentation,
issues, discussions and releases. GitHub's own privacy statement governs what happens once you
follow those links.

## Self-hosted and desktop deployments

{{< product >}} itself — the desktop app, the self-hosted server, and the mobile client — is a
separate piece of software from this website, and this website does not operate a hosted instance
of it. Whoever runs a deployment (yourself, on your own machine or server) controls what data that
deployment stores and where it sends it: your model provider keys, your bots' conversations and
memory, and any connectors you configure. See
[Self-hosting]({{< repo-link "docs/self-host.md" >}}) and
[Self-host secrets]({{< repo-link "docs/self-host-secrets.md" >}}) for exactly what a deployment
stores and where.
