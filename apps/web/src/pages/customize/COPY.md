# Customization copy inventory

Every fixed label and recoverable error introduced by the customization feature is quoted below. Existing labels reused by the new pages are included. Manifest-supplied names, descriptions, field titles, categories, and dates remain user data, not shipped copy.

The brief requires the page descriptions and installation footer. Labels identify controls, groups, and state. Additional details appear only in configuration, logs, install review, or a failed action; keeping those details hidden until needed keeps the lists concise.
