# System copy

Every added label, description, action, status and native failure message is quoted below.
Values in braces are runtime substitutions, not example personal data.

Row labels remain visible so controls have stable accessible names. Each description is one
sentence explaining a native effect or its scope; removing it would obscure where the setting
applies. Errors, recording state and routine counts appear only when relevant. Bot selection
is shown inside quick access, where a destination is required; it does not add a settings row.
The storage transaction messages below are covered by tests but are not exposed while move
controls are disabled.

The fixed shortcut values are "Off", "Alt+Space", "Control+Space",
"CommandOrControl+Shift+V", "CommandOrControl+Shift+D" and "CommandOrControl+D".
On macOS the displayed modifiers are "⌥", "⌃" and "⌘"; on Windows and Linux the
command-or-control modifier is displayed as "Ctrl". Labels preserve "+Space", "+Shift+V",
"+Shift+D" or "+D" as applicable. Domain, bot name, version and folder values come from
validated runtime state rather than literal example accounts or paths.
